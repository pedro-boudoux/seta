COOPER — "WORLD OF LOGOTYPES" — EXTRACTED LOGOTYPES (SMOOTHED)
==============================================================

Identical set and naming to ../world-of-logotypes (same entries,
same manifest) — only the tracing differs.

Smoothing applied (deliberately gentle, to preserve shape):
  1. Gaussian blur (sigma 2.0 px at 600 dpi — about 0.5% of a
     typical mark) before thresholding, which removes scan/JPEG
     edge wobble while leaving the ink boundary where it was.
  2. Rounder potrace curve settings (-a 1.2 -O 0.4).

Outlines are slightly calmer; overall geometry is unchanged.
For the maximally faithful (unsmoothed) versions, use
../world-of-logotypes.
