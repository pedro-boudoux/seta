TRADEMARKS AND SYMBOLS VOL. 2 — EXTRACTED LOGOS (SMOOTHED VARIANT)
=================================================================

Identical set and naming to ../logos-svg (same boxes, same printed
numbers, same manifest) — only the tracing differs.

Smoothing applied (deliberately gentle, to preserve shape):
  1. Gaussian blur (sigma 2.0 px at 900 dpi — about 0.5% of a typical
     mark) before thresholding, which removes scan/JPEG edge wobble
     while leaving the ink boundary where it was.
  2. Rounder potrace curve settings (-a 1.2 -O 0.4): fewer hard corner
     segments, more flowing beziers.

Halftone/stipple marks keep every dot (verified: the dithered eye keeps
all 221 dots, unmerged). Outlines are slightly calmer; overall geometry
is unchanged.

If you want the maximally faithful (unsmoothed) versions, use
../logos-svg.
